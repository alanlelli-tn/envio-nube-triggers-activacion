# Triggers de activación de Envío Nube – Resultados

Tablero estático (Next.js 14, App Router) con los resultados de los triggers in-app
"Agregar medio de envío" y "Agregar envío personalizado" (Lifecycle AR).

- Los números y el corte de datos se editan en `app/content.js`.
- Deploy automático en Vercel al hacer push a `main` (Framework Preset: Next.js, Output Directory por defecto).
- Sin variables de entorno ni datos de merchants: solo agregados.
